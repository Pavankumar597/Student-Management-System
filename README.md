# 🎓 Student Management System

A responsive and user-friendly **Student Management System** built using HTML, CSS, and JavaScript. This application helps manage student records efficiently by allowing users to add, view, search, and delete student information.

The application also provides a dashboard with student statistics and stores records using the browser's LocalStorage.

## 🚀 Features

- **Dashboard Overview** – Displays total students, male students, female students, and average marks.
- **Add Students** – Register students with personal and academic details.
- **View Student Records** – Display all student information in a structured table.
- **Search Students** – Search students by name, roll number, or course.
- **Delete Students** – Remove student records with confirmation.
- **Data Persistence** – Save student records using LocalStorage.
- **Responsive Design** – Adaptable layout for desktop, tablet, and mobile devices.

## 📊 Dashboard Information

The dashboard automatically calculates and displays:

- Total number of registered students.
- Number of male students.
- Number of female students.
- Average marks of all registered students.

## 💾 Data Storage

This project uses the browser's **LocalStorage API** to store student records.

- Student data remains available after refreshing the page.
- Records are stored locally in the browser.
- No external database or backend server is required.

**Note:** Data is browser-specific and can be lost if the browser's site data is cleared.
